# TastyBytes - Digital Recipe Book

## Setup Instructions
1. Install XAMPPWAMP on your computer.
2. Copy the `recipe_book` folder into `htdocs` directory.
3. Open phpMyAdmin (`httplocalhostphpmyadmin`) and create a database named `recipe_book`.
4. Import the `database.sql` file located in the project root directory.
5. Open your browser and go to `httplocalhostrecipe_bookindex.php
